## Common Commands

### Install dependencies
```bash
npm install --legacy-peer-deps
```

### Compile contract
```bash
npx hardhat compile
```

### Run tests
```bash
npx hardhat test
```

### Deploy to Sepolia
```bash
npx hardhat run scripts/deploy.js --network sepolia
```

### Verify on Etherscan
```bash
npx hardhat verify --network sepolia <CONTRACT_ADDRESS> "<OWNER_1>" "<OWNER_2>" "<OWNER_3>" <THRESHOLD>
```

### Start monitoring
```bash
npx hardhat run scripts/startMonitor.js --network sepolia
```

### Start frontend
```bash
cd frontend && npm start
```

### Run uninstall script
```bash
bash scripts/uninstall.sh
```
